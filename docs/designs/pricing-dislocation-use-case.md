# Design: Pricing Dislocation Use Case — Dashboard Demo

Generated by /plan-ceo-review on 2026-03-17
Branch: main | Mode: SELECTIVE EXPANSION

## Goal

Transform the Dislocation Analysis tab from a flat data display into a self-narrating detective story for C-level pitch demos. The presenter scrolls (or steps) through a narrative arc: "the model was sound → something shifted → here's what and where → here's what to do."

## Context

This is the centerpiece use case for the analytics transformation pitch. The dashboard establishes foundation (Phases 2-4, built). This use case demonstrates the value of narrative-driven analytics. Companion work in the `travelers-nao-agent` repo will add the AI chat side of the demo.

## Accepted Scope

### Core (from original plan, Steps 1-4)
1. **2025 Model Validation** — Extract validation2025 from existing JSONB in `dislocation_analysis` table. Display as compact bar chart with A/E ~1.0, green tones. Proves the model worked before the shift.
2. **Destination-Type A/E Chart** — Render the already-computed `aeByDestType` data as a horizontal bar chart (same pattern as `ae-by-segment.tsx`). Caribbean reveals as the smoking gun.
3. **Narrative Section Structure** — Restructure dislocation tab into 5 named sections with headers and annotations: "The Model Was Sound" → "Something Shifted" → "Frequency & Severity" → "When and Where" → "Rate Adequacy".

### Expansions (from CEO review cherry-picks)
4. **Auto-Generated Diagnosis Card** — Plain-English summary at top of tab derived from data: "Baseline segment deteriorated 23%, driven by frequency increases concentrated in Aug-Oct, with Caribbean at highest A/E." Template interpolation, not AI-generated.
5. **Color-Coded 2025/2026 Contrast** — Green tones for 2025 sections (healthy), amber/red for 2026 (deteriorating). Subtle background tints and card borders.
6. **Presenter Stepper Mode** — Toggle that collapses sections into progressive disclosure. "Next" reveals each section one at a time. Ephemeral React state (no localStorage). CSS transitions.
7. **Cross-Tab "Investigate on Map" Link** — From destination-type A/E chart, link to Exposure Map tab pre-filtered to Caribbean. Uses existing setActiveTab + setDestinationType.
8. **Key Finding Callout Badges** — "Worst" badges on highest-A/E bars and heatmap cells. Subtle pulse or badge overlay.

## Architecture

```
page.tsx (Dislocation Tab)
  └── StepperController (useState: currentStep, presenterMode)

```

## Key Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| 2025 data source | Extract from existing JSONB | Simpler, no new data pipeline |
| Stepper state | Ephemeral React useState | Demo is 5 min, persistence adds needless complexity |
| Cross-tab fetch | Let existing useEffect handle | Zero new fetching code |
| Steps 5-7 (nao agent) | Removed — separate repo | Commit 942a738 moved nao agent out |
| Cross-tab link wiring | Inline button in page.tsx | Minimal diff, not worth a prop interface for one onClick |
| A/E chart DRY | Shared AEBarChart component | Segment + dest-type charts share 90% code + callout badge logic |
| Dislocation tab extraction | New dislocation-tab.tsx | Tab now too complex for inline in 890-line page.tsx |
| Test runner | Vitest | Boring-by-default for Next.js, fast, TS-native |

## Visual Design Spec (from design review)

### Diagnosis Hero Banner
- Full-width Card with subtle amber/destructive tint: `bg-[var(--status-alert)]/10`
- Title: `text-xl font-bold` with Lucide `AlertTriangle` icon (amber, `h-6 w-6`)
- Title text: "Portfolio Under Stress" (data-driven — could be "Portfolio Healthy" if A/E < 1.0)
- Body: `text-base` paragraph with interpolated metrics, bold key numbers
- Footer row: 3 mini-KPIs inline (Portfolio A/E, Worst Segment, Worst Month)
- Always visible (not collapsed by stepper)

### Section Color Coding
- **Section 1 (2025 Validation):** `border-l-4 border-emerald-400 bg-emerald-50/30` (dark: `bg-emerald-950/20`)
- **Section 2 (2026 KPIs):** `border-l-4 border-red-400 bg-red-50/30` (dark: `bg-red-950/20`)
- **Sections 3-5:** No tint — standard `bg-card`
- Uses existing `--status-good` and `--status-alert` CSS variables at low opacity

### Stepper Controls
- Toolbar row at top of tab: `flex items-center justify-between`
- Toggle: text button "Presenter Mode" with on/off state (`variant="ghost" size="sm"`)
- Navigation: `[◀ Prev]` `Step 2 of 6` `[Next ▶]` — shadcn Button `variant="outline" size="sm"`
- Step indicator: `text-sm text-muted-foreground`
- Disabled state: Prev disabled at step 0, Next disabled at step 5
- Transition: `transition-all duration-300 ease-in-out` with `opacity-0 → opacity-100`

### Callout Badges
- Inline shadcn Badge with `variant="destructive"` next to worst item's label
- Text: "Worst" — static, no animation
- Applied to: highest-A/E bar in segment chart, highest-A/E bar in dest-type chart, worst cell in heatmap
- If tied: badge on all tied items
- If all A/E ≤ 1.05: no badges shown

### Cross-Tab Link
- Text link (not button): `text-sm text-muted-foreground hover:text-foreground cursor-pointer`
- Text: "Investigate Caribbean on Map →"
- Positioned below the dest-type A/E chart
- Only shown when Caribbean has highest A/E (data-driven)

### Interaction States
